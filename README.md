# MAX Chat · GREEN-API

Минималистичный React-клиент для отправки и получения текстовых сообщений в
мессенджере MAX через GREEN-API.

## Возможности

- подключение по `apiUrl`, `idInstance` и `apiTokenInstance`;
- проверка состояния MAX-инстанса;
- создание чата по номеру телефона;
- проверка наличия номера в MAX методом `CheckAccount`;
- отправка текстовых сообщений методом `SendMessage`;
- получение сообщений через HTTP API методами `ReceiveNotification` и
  `DeleteNotification`;
- адаптивный интерфейс в стилистике веб-версии MAX;
- доступная навигация с клавиатуры, семантические статусы и поддержка
  `prefers-reduced-motion`;
- обработка ошибок сети, тайм-аутов и повторное подключение к очереди
  уведомлений.

## Локальный запуск

Рекомендуется Node.js 20. Минимальная поддерживаемая версия — 18.20.

```bash
npm install
npm run dev
```

После запуска откройте адрес, указанный Vite, и введите параметры инстанса из
личного кабинета GREEN-API.

## Перед использованием

1. Создайте и авторизуйте MAX-инстанс в GREEN-API.
2. В настройках инстанса оставьте поле `webhookUrl` пустым.
3. Включите «Получать уведомления о входящих сообщениях и файлах».

Токен инстанса не хранится в репозитории или постоянном хранилище браузера.

## Архитектура и безопасность

- UI-компоненты отделены от клиента GREEN-API и цикла получения уведомлений.
- Токен существует только в памяти открытой вкладки: приложение не записывает
  его в `localStorage`, `sessionStorage`, логи или исходный код.
- Внешний `apiUrl` принимается только по HTTPS; HTTP разрешён исключительно для
  локальной разработки.
- Каждый обработанный элемент очереди удаляется методом `DeleteNotification`,
  а идентификаторы сообщений дедуплицируются на клиенте.
- Создание чата поддерживает номера России и Беларуси, как требует метод
  `CheckAccount` для MAX.
